# ValeDouroArcade

Protótipo web arcade do universo ValeDouro.

## v0.0.1
Primeiro protótipo de movimento e combate:
- seleção de Mauricius, Cassandra Arven, Aurus e Brokk Pedra-Funda;
- Aurus com escolha Lâmina/Arco;
- movimento, salto, plataformas e câmera lateral;
- ataque básico;
- Aurus/Arco com 20 flechas iniciais, limite 30 e adaga quando zerar;
- HP e inimigos simples;
- morte definitiva do personagem na run;
- reinício da mesma fase escolhendo outro personagem.

A arte é deliberadamente provisória nesta etapa.

## Executar
Abra por um servidor HTTP local ou publique via GitHub Pages. O jogo usa Phaser via CDN.

## Controles
- WASD / setas: movimento
- Espaço / W / seta para cima: salto
- Clique do mouse: ataque / mira e disparo no estilo Arco

Consulte `GAME_DESIGN.md` para as regras canônicas de gameplay.
